# ☕ Brewly

### Run Your Cafe, Smarter.

Brewly is a modern cafe management SaaS platform designed to help cafe owners manage their daily operations from one place.

The platform brings together orders, menu management, inventory, customers, staff, and business analytics into a single dashboard.

---

## Project Overview

Brewly is being built as a full-stack SaaS application with a separate frontend and backend architecture.

The goal of the project is to create a practical, scalable cafe management system while exploring real-world full-stack development concepts.
